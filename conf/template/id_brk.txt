# (idm0.brk_rate, 3 Nm/s) until the axis moves idm0.brk_win (0.002 rad),

# back; about 15 s on a vertical axis. the velocity integrator is parked
# for the run (pid0.vel_d = idm0.vel_d_pid, 1e6 while ramping).
# starts on enable; disable to abort or clear. run it with dob0.k = 0
# (dob cancels the ramp) and the brake released.
