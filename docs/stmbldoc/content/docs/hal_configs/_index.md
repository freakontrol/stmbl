# HAL Configs

A config is a complete drive configuration from the conf/ folder of the repository, for one motor and machine. It sets the `conf0` motor and tuning parameters and links the templates it needs (see [HAL Templates](/docs/hal_templates/_index.md)). Load one into the drive with the Config window of [Servoterm](/docs/getting_started/servoterm.md), then save it to flash. The pages in this section show the configs in the repository, which are useful as starting points for a similar motor.
