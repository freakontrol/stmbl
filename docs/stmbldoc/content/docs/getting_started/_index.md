# Getting Started

These pages take a drive from first power-up to a tuned axis. Read the [Introduction](/docs/introduction.md) first, and flash the firmware as described there.

* [Servoterm](/docs/getting_started/servoterm.md): connect to the drive, edit and save the config.
* [Pinouts](/docs/getting_started/pinouts.md): connector pin assignments.
* [Feedback](/docs/getting_started/feedback.md): set up the motor encoder or resolver.
* [Motor](/docs/getting_started/motor.md): find and enter the motor parameters.
* [Tuning](/docs/getting_started/tuning.md): tune the current, speed and position loops.
* [LinuxCNC](/docs/getting_started/linuxcnc.md): connect the drive to LinuxCNC over Mesa smart serial.
